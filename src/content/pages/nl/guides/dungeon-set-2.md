Dungeon Set 2, ook Tier 0.5 genoemd, is een lange questketen die je Dungeon Set 1 stuk voor stuk opwaardeert. In WoW Forever krijgt elke spec een eigen set, en de meeste stukken zijn pre-raid best in slot. Deze gids loopt de keten door in vier delen.

| | |
|---|---|
| Level | 58 |
| Start | <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16013">Deliana</a> in Ironforge of <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16012">Mokvar</a> in Orgrimmar |
| Reputatie | Honored bij de Argent Dawn, vanaf deel 3 |
| Goud | 220 aan kosten, rond de 600 tot 700 met materialen |
| Tijd | 12 tot 20 uur |
| Beloning | 8 stukken, setbonus bij 3 en 6, een Legacy Point |

## Voor je begint

**Je hebt niet de volledige Dungeon Set 1 nodig.** Elk deel vraagt alleen de stukken die het opwaardeert, dus je kan beginnen met alleen de polsen. De quests nemen die stukken in, dus leg dubbele stukken in je bank voor elke inlevering.

**Wat nieuw is in Forever.** De oproeping in Silithus is weg. <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=270451">Executor Asharell</a> in de Burning Steppes vervangt The Duke of Cynders, dus je hebt geen Twilight Cultist-gear of Cenarion Circle-reputatie meer nodig. Elke class heeft een eigen versie van de quests bij Deliana en Mokvar. De naam is voor elke class dezelfde.

**Koop de <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=21939"><img class="wf-wh__icon" src="/wh/inv_staff_18.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Fel Elemental Rod</a> op tijd.** <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16015">Vi'el</a> verkoopt hem voor 40 goud, maar volgens spelers stijgt de prijs naar 50 zodra je de quest hebt.

3. **Lever in.** Breng de stalen, je Dungeon Set 1-polsen en 20 goud terug voor je Tier 0.5-polsen.

Hij loopt rond op de brug.
2. **Red Ysida.** Voor <a href="https://www.wowhead.com/forever/quest=8945">Dead Man's Plea</a> versla je <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=10440">Baron Rivendare</a> in [Stratholme: Undead](/nl/guides/dungeons/stratholme-undead/). 3. **Breng het medaillon.** <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16031">Ysida Harmon</a> geeft je <a href="https://www.wowhead.com/forever/quest=8946">Proof of Life</a>: breng het terug naar Anthion.
4. **Betaal de banier.** Voor <a href="https://www.wowhead.com/forever/quest=8947">Anthion's Strange Request</a> breng je Anthion 3 <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=11371"><img class="wf-wh__icon" src="/wh/inv_ingot_mithril.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Dark Iron Bar</a>, 20 <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=12810"><img class="wf-wh__icon" src="/wh/inv_misc_rune_05.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Enchanted Leather</a>, 3 <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=14342"><img class="wf-wh__icon" src="/wh/inv_fabric_moonrag_01.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Mooncloth</a> en 4 <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=15407"><img class="wf-wh__icon" src="/wh/inv_misc_pelt_bear_03.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Cured Rugged Hide</a>.
5. **Zoek Falrin.** <a href="https://www.wowhead.com/forever/quest=8948">Anthion's Old Friend</a> stuurt je naar <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16032">Falrin Treeshaper</a> in de bibliotheek van [Dire Maul North](/nl/guides/dungeons/dire-maul-north/). Iemand in de groep heeft de <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=18249"><img class="wf-wh__icon" src="/wh/inv_misc_key_10.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Crescent Key</a> nodig van <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=14354">Pusillin</a> in Dire Maul East.
6. **Verzamel 25 warbeads.** Voor <a href="https://www.wowhead.com/forever/quest=8949">Falrin's Vendetta</a> haal je 25 <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=21982"><img class="wf-wh__icon" src="/wh/inv_jewelry_necklace_19.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Ogre Warbeads</a> bij ogres in Dire Maul of Blackrock Spire.

8. **Versla Theldren.** Voor <a href="https://www.wowhead.com/forever/quest=9015">The Challenge</a> ga je naar de Ring of the Law in [Blackrock Depths](/nl/guides/dungeons/blackrock-depths/). Zet de <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=21986"><img class="wf-wh__icon" src="/wh/inv_brd_banner.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Banner of Provocation</a> neer voor <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=10096">High Justice Grimstone</a> verschijnt en stap dan op het rooster: <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16059">Theldren</a> en zijn team komen binnen. Neem de <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=22047"><img class="wf-wh__icon" src="/wh/inv_jewelry_necklace_28.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Top Piece of Lord Valthalak's Amulet</a> en breng hem naar Anthion.
9. **Lever in.** Geef bij Deliana of Mokvar je Dungeon Set 1-laarzen, -broek en -schouders af.

Start Grimstone eerst het gewone arena-event, dan komt Theldren niet. De groep moet de dungeon dan resetten.

## Deel 4: helm en borststuk

| | |
|---|---|
| Beloning | Tier 0.5-helm en -borststuk, een Legacy Point, de <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=22057"><img class="wf-wh__icon" src="/wh/inv_misc_enggizmos_23.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Brazier of Invocation</a> |

|---|---|
