El Dungeon Set 2, también llamado Tier 0.5, es una larga cadena de misiones que mejora tu Dungeon Set 1 pieza a pieza. En WoW Forever cada especialización tiene su propio set, y la mayoría de las piezas son best in slot antes de las bandas. Esta guía recorre la cadena en cuatro partes.

| | |
|---|---|
| Nivel | 58 |
| Inicio | <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16013">Deliana</a> en Ironforge o <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16012">Mokvar</a> en Orgrimmar |
| Reputación | Honored con la Argent Dawn, desde la parte 3 |
| Oro | 220 en tarifas, unos 600 a 700 con materiales |
| Tiempo | 12 a 20 horas |
| Recompensa | 8 piezas, bonus de set con 3 y 6, un Legacy Point |

## Antes de empezar

**No necesitas el Dungeon Set 1 completo.** Cada parte solo pide las piezas que mejora, así que puedes empezar solo con los brazales. Las misiones se quedan con esas piezas: guarda las repetidas en el banco antes de cada entrega.

**Qué es nuevo en Forever.** La invocación de Silithus desaparece. <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=270451">Executor Asharell</a> en las Burning Steppes sustituye a The Duke of Cynders, así que ya no necesitas el equipo Twilight Cultist ni la reputación con Cenarion Circle. Cada clase tiene su propia versión de las misiones de Deliana y Mokvar. El nombre es el mismo para todas las clases.

**Compra la <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=21939"><img class="wf-wh__icon" src="/wh/inv_staff_18.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Fel Elemental Rod</a> pronto.** <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16015">Vi'el</a> la vende por 40 de oro, pero según los jugadores el precio sube a 50 en cuanto tienes la misión.

3. **Entrega.** Lleva las muestras, tus brazales del Dungeon Set 1 y 20 de oro para recibir los brazales Tier 0.5.
