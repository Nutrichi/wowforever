Neuf quêtes sont pour la Horde, surtout depuis Kargath dans les Badlands. Sept sont pour l’Alliance, depuis Morgan's Vigil dans les Burning Steppes, Ironforge et Kharanos. Six sont ouvertes aux deux. Les deux longues chaînes se terminent avec Emperor Dagran Thaurissan : The Royal Rescue pour la Horde et The Fate of the Kingdom pour l’Alliance. Attunement to the Core ouvre Molten Core.

Les niveaux viennent des données de Forever. Les récompenses n’y sont pas encore, donc les cartes ci-dessous le disent ; cette page les ajoute dès qu’elles sont connues.
