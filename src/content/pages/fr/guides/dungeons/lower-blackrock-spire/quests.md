Les quêtes de la Horde commencent à Kargath dans les Badlands, celles de l’Alliance à Morgan's Vigil dans les Burning Steppes. Flame Crest, aussi dans les Burning Steppes, a trois quêtes pour les deux factions. Seal of Ascension ouvre [Upper Blackrock Spire](/fr/guides/dungeons/upper-blackrock-spire/), et Warlord's Command lance la longue chaîne de la Horde vers Onyxia's Lair.

Les niveaux viennent des données de Forever. Les récompenses n’y sont pas encore, donc les cartes ci-dessous le disent ; cette page les ajoute dès qu’elles sont connues.
