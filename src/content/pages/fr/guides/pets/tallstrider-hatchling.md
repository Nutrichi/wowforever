## Comment l'obtenir

Elle tombe sur <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=2172">Strider Clutchmother</a> à Darkshore. Dans les données de butin de Wowhead, elle tombe dans environ 0,2 % des victoires.

## Bon à savoir

La base de données de Wowhead indique que la mascotte vaut pour tout le compte : apprise une fois, elle serait là pour chaque personnage. Blizzard ne l'a pas confirmé.
