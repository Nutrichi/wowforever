Le Dungeon Set 2, aussi appelé Tier 0.5, est une longue chaîne de quêtes qui améliore votre Dungeon Set 1 pièce par pièce. Dans WoW Forever, chaque spécialisation a son propre set, et la plupart des pièces sont best in slot avant les raids. Ce guide parcourt la chaîne en quatre parties.

| | |
|---|---|
| Niveau | 58 |
| Départ | <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16013">Deliana</a> à Ironforge ou <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16012">Mokvar</a> à Orgrimmar |
| Réputation | Honored auprès de l’Argent Dawn, dès la partie 3 |
| Or | 220 en frais, environ 600 à 700 avec les composants |
| Durée | 12 à 20 heures |
| Récompense | 8 pièces, bonus de set à 3 et 6, un Legacy Point |

## Avant de commencer

**Pas besoin du Dungeon Set 1 complet.** Chaque partie ne demande que les pièces qu’elle améliore, vous pouvez donc commencer avec les seuls poignets. Les quêtes prennent ces pièces : rangez vos doublons en banque avant chaque rendu.

**Ce qui change dans Forever.** L’invocation en Silithus disparaît. <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=270451">Executor Asharell</a> dans les Burning Steppes remplace The Duke of Cynders, donc plus besoin de l’équipement Twilight Cultist ni de la réputation Cenarion Circle. Chaque classe a sa propre version des quêtes de Deliana et Mokvar. Le nom est le même pour toutes les classes.

**Achetez la <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=21939"><img class="wf-wh__icon" src="/wh/inv_staff_18.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Fel Elemental Rod</a> tôt.** <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16015">Vi'el</a> la vend 40 pièces d’or, mais selon des joueurs le prix monte à 50 une fois la quête acceptée.

## Partie 3 : bottes, jambières et épaulières

| | |
|---|---|
| Récompense | Bottes, jambières et épaulières Tier 0.5, bonus à 6 pièces |
| Il vous faut | Honored auprès de l’Argent Dawn, les bottes, jambières et épaulières du Dungeon Set 1, les composants de la partie 3 |
| Groupe | Stratholme, Dire Maul et Blackrock Depths |

1. **Trouvez Anthion.** Utilisez le <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=22115"><img class="wf-wh__icon" src="/wh/inv_misc_enggizmos_20.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Extra-Dimensional Ghost Revealer</a> à la porte principale de Stratholme dans les Eastern Plaguelands (/way 31.0 12.8) pour voir <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16016">Anthion Harmon</a>. Il erre sur le pont.
2. **Sauvez Ysida.** Pour <a href="https://www.wowhead.com/forever/quest=8945">Dead Man's Plea</a>, battez <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=10440">Baron Rivendare</a> dans [Stratholme: Undead](/fr/guides/dungeons/stratholme-undead/). Dès que vous ouvrez la deuxième porte de service, vous avez 45 minutes pour lancer le combat. Mourir retire le débuff du chrono, mais le run compte toujours.
3. **Rapportez le médaillon.** <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16031">Ysida Harmon</a> vous donne <a href="https://www.wowhead.com/forever/quest=8946">Proof of Life</a> : rapportez-le à Anthion.
4. **Payez la bannière.** Pour <a href="https://www.wowhead.com/forever/quest=8947">Anthion's Strange Request</a>, apportez à Anthion 3 <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=11371"><img class="wf-wh__icon" src="/wh/inv_ingot_mithril.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Dark Iron Bar</a>, 20 <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=12810"><img class="wf-wh__icon" src="/wh/inv_misc_rune_05.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Enchanted Leather</a>, 3 <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=14342"><img class="wf-wh__icon" src="/wh/inv_fabric_moonrag_01.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Mooncloth</a> et 4 <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=15407"><img class="wf-wh__icon" src="/wh/inv_misc_pelt_bear_03.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Cured Rugged Hide</a>.
5. **Trouvez Falrin.** <a href="https://www.wowhead.com/forever/quest=8948">Anthion's Old Friend</a> vous envoie voir <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16032">Falrin Treeshaper</a> dans la bibliothèque de [Dire Maul North](/fr/guides/dungeons/dire-maul-north/). Quelqu’un du groupe a besoin de la <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=18249"><img class="wf-wh__icon" src="/wh/inv_misc_key_10.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Crescent Key</a> de <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=14354">Pusillin</a> dans Dire Maul East.
6. **Récoltez 25 warbeads.** Pour <a href="https://www.wowhead.com/forever/quest=8949">Falrin's Vendetta</a>, prenez 25 <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=21982"><img class="wf-wh__icon" src="/wh/inv_jewelry_necklace_19.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Ogre Warbeads</a> sur les ogres de Dire Maul ou de Blackrock Spire.
7. **Apportez l’essence.** Pour <a href="https://www.wowhead.com/forever/quest=8950">The Instigator's Enchantment</a>, apportez à Falrin 1 <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=22224"><img class="wf-wh__icon" src="/wh/inv_poison_mindnumbing.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Jeering Spectre's Essence</a> des fantômes de [Dire Maul West](/fr/guides/dungeons/dire-maul-west/), plus 8 <a class="wf-wh wf-q3" href="https://www.wowhead.com/forever/item=14344"><img class="wf-wh__icon" src="/wh/inv_enchant_shardbrilliantlarge.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Large Brilliant Shard</a> et 4 <a class="wf-wh wf-q2" href="https://www.wowhead.com/forever/item=20520"><img class="wf-wh__icon" src="/wh/spell_shadow_sealofkings.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Dark Rune</a>.
8. **Battez Theldren.** Pour <a href="https://www.wowhead.com/forever/quest=9015">The Challenge</a>, allez au Ring of the Law dans [Blackrock Depths](/fr/guides/dungeons/blackrock-depths/). Posez la <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=21986"><img class="wf-wh__icon" src="/wh/inv_brd_banner.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Banner of Provocation</a> avant l’arrivée de <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=10096">High Justice Grimstone</a>, puis marchez sur la grille : <a class="wf-wh wf-plain" href="https://www.wowhead.com/forever/npc=16059">Theldren</a> et son équipe entrent. Prenez le <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=22047"><img class="wf-wh__icon" src="/wh/inv_jewelry_necklace_28.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Top Piece of Lord Valthalak's Amulet</a> et apportez-le à Anthion.
9. **Rendez la quête.** Chez Deliana ou Mokvar, donnez vos bottes, jambières et épaulières du Dungeon Set 1.

Si Grimstone lance d’abord l’événement normal de l’arène, Theldren ne vient pas. Le groupe doit alors réinitialiser le donjon.

## Partie 4 : casque et plastron

| | |
|---|---|
| Récompense | Casque et plastron Tier 0.5, un Legacy Point, le <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=22057"><img class="wf-wh__icon" src="/wh/inv_misc_enggizmos_23.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Brazier of Invocation</a> |

## Où tombe le Dungeon Set 1

Cinq emplacements viennent du même endroit pour toutes les classes. Poignets, ceinture et gants sont Bind on Equip : vous pouvez aussi les acheter à l’Auction House.

| Emplacement | Où |
|---|---|
| **Poignets, ceinture** | Trash dans Blackrock Spire, Scholomance et Stratholme |
| **Tête** | Darkmaster Gandling, [Scholomance](/fr/guides/dungeons/scholomance/) |
| **Torse** | General Drakkisath, [Upper Blackrock Spire](/fr/guides/dungeons/upper-blackrock-spire/) |
| **Jambes** | Baron Rivendare, [Stratholme: Undead](/fr/guides/dungeons/stratholme-undead/) |

Gants, bottes et épaulières tombent d’un boss différent selon la classe :

| Classe | Gants | Bottes | Épaules |
|---|---|---|---|
| **Druid** | The Unforgiven, Stratholme | Mother Smolderweb, Lower Blackrock Spire | Gizrul the Slavener, Lower Blackrock Spire |
| **Hunter** | War Master Voone, Lower Blackrock Spire | Nerub'enkan, Stratholme | Overlord Wyrmthalak, Lower Blackrock Spire |
| **Mage** | Doctor Theolen Krastinov, Scholomance | Hearthsinger Forresten, Stratholme | Ras Frostwhisper, Scholomance |
| **Paladin** | Timmy the Cruel, Stratholme | Balnazzar, Stratholme | The Beast, Upper Blackrock Spire |
| **Priest** | Archivist Galford, Stratholme | Maleki the Pallid, Stratholme | Solakar Flamewreath, Upper Blackrock Spire |
| **Rogue** | Shadow Hunter Vosh'gajin, Lower Blackrock Spire | Rattlegore, Scholomance | Cannon Master Willey, Stratholme |
| **Shaman** | Pyroguard Emberseer, Upper Blackrock Spire | Highlord Omokk, Lower Blackrock Spire | Gyth, Upper Blackrock Spire |
| **Warlock** | Trash, Scholomance | Baroness Anastari, Stratholme | Jandice Barov, Scholomance |
| **Warrior** | Ramstein the Gorger, Stratholme | Kirtonos the Herald, Scholomance | Warchief Rend Blackhand, Upper Blackrock Spire |
