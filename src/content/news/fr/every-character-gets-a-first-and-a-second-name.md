Chaque personnage de World of Warcraft: Forever porte deux noms. Ensemble, ils forment un nom complet qui doit être unique dans une région. Blizzard a expliqué le système le 21 septembre. Cela revient à un prénom et à un nom de famille.

![Le champ Full Name à la création du personnage, avec une case pour le nom principal et une pour le second nom](../../../assets/posts/2026-09-21-wow-forever-full-name-field.png)

## C'est la paire qui compte

Un prénom que quelqu'un d'autre a déjà pris n'est pas perdu d'office, écrit Blizzard. Ce qui doit être libre, c'est la combinaison entière. Deux personnages peuvent porter le même prénom tant que leurs noms complets diffèrent.

Comme Forever n'a pas de realms, cette vérification porte sur toute une région plutôt que sur un serveur. Blizzard y voit une part du travail pour garder les noms reconnaissables dans la durée.

## Ce que peut faire un second nom

Le second nom doit élargir le choix et non le réduire, écrit Blizzard. Il peut évoquer une famille, un lieu, une réputation ou quelque chose qui fonctionne comme un titre.

Blizzard donne son propre exemple : Asha Brightvale, Thalen Brightvale et Mira Brightvale partagent un second nom de style familial tandis que chacun garde un prénom différent. Une guilde peut faire pareil avec un thème commun, tant que chaque combinaison complète est encore libre dans la région.

## Désactiver le second nom

Qui préfère plus sobre peut cacher le second nom dans le monde. Cela se trouve dans le menu du jeu sous Options, puis Nameplates, comme la case My Secondary Name.

![Les options Nameplates dans le jeu, avec la case My Secondary Name tout en haut](../../../assets/posts/2026-09-21-wow-forever-nameplates-secondary-name.png)

Le second nom disparaît alors au-dessus du personnage, écrit Blizzard, mais il reste visible dans le chat.

## Les règles ne se sont pas relâchées

Les noms suivent le code de conduite du jeu. Certains mots, orthographes et suites de caractères répétés restent interdits, tout comme les noms qui sèment la confusion ou se font passer pour Blizzard ou l'équipe de World of Warcraft.

Répartir un mot interdit sur les deux noms n'y change rien, écrit Blizzard, car le système peut évaluer les deux parties ensemble. Blizzard [avait déjà retiré l'accès à la bêta](/fr/news/offensive-names-cost-players-their-beta-access/) à des joueurs pour leur nom plus tôt ce week-end.

## Réserver un nom

L'Early Name Reservation court du 27 octobre au 3 novembre 2026, pour les achats qui y donnent droit. Les noms partent dans l'ordre d'arrivée, et un nom souhaité n'est jamais garanti.

Le joueur dont la combinaison est prise ou refusée doit en choisir une autre, ou se rabattre sur le générateur de noms aléatoires du jeu.
