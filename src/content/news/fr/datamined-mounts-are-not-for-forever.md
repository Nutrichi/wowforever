La dernière build bêta de World of Warcraft: Forever, du soir du 16 octobre, contient une série de nouveaux objets de collection : trois montures, trois mascottes, un jouet et deux ensembles de transmo. Les dataminers les ont trouvés en quelques heures. Beaucoup de joueurs ont jugé que ces modèles ne collent pas au style classique de Forever. La même nuit, le community manager Kaivax a répondu sur les forums officiels :

> "A number of art assets were recently datamined in the latest Beta build of WoW Forever. While we appreciate the feedback and discussion online, please be advised that these assets are not intended for this version of World of Warcraft."

Ces objets n'arrivent donc pas dans Forever, du moins pas pour l'instant. Pour quelle version ils sont prévus, Blizzard ne le dit pas. Les versions de World of Warcraft partagent beaucoup de fichiers, et des ressources d'une version apparaissent parfois dans les données d'une autre.

Le jouet <a class="wf-wh wf-q1" href="https://www.wowhead.com/forever/item=288185"><img class="wf-wh__icon" src="/wh/inv_10_tailoring2_tent_color3.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Adventurer's Tent</a> pose une petite tente pendant 15 minutes. Chaque Camp Tent placée pendant ce temps prend l'apparence de l'Adventurer's Tent. Le fonctionnement du camping dans Forever est expliqué dans [notre guide du camping](/fr/guides/camping/).
