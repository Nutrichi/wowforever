WeakAuras ne fonctionne pas dans World of Warcraft: Forever. Le jeu applique les restrictions d'addons que Midnight a apportées au jeu moderne, qui limitent ce que les addons voient et font en combat. Des outils intégrés prennent une partie du relais, à commencer par un Cooldown Manager.

## Le Cooldown Manager

Le Cooldown Manager lit vos buffs et vos barres d'action et affiche les sorts choisis dans son propre cadre, bijoux et potions compris. Il est désactivé par défaut : activez-le dans Options, Advanced Options, placez-le avec Edit Mode et tapez /cdm pour choisir les sorts.

![L'option Enable Cooldown Manager dans la fenêtre Options, avec les boutons Edit Mode et Advanced Cooldown Settings, une capture d'écran de World of Warcraft: Forever](../../../assets/posts/2026-10-30-wow-forever-cooldown-manager-option.jpg)

Ce n'est pas un remplacement complet. Les déclencheurs personnalisés, le suivi de combat avancé et l'aide à la rotation ne sont pas possibles avec les nouvelles règles.

## D'autres outils dans le jeu

Les mêmes Advanced Options contiennent un **Damage Meter**, avec un menu déroulant pour ce qu'il affiche et d'autres fenêtres derrière l'engrenage. Un **Swing Timer** indique quand tombe la prochaine attaque automatique.

## Les addons restent autorisés

Forever n'interdit pas les addons. Les addons d'interface, de sacs et de barres d'action fonctionnent encore, tant qu'ils sont faits pour Forever. Les anciens addons Classic ne sont pas garantis. Les étapes pour chaque outil sont dans notre [guide des outils d'interface intégrés](/fr/guides/built-in-ui-tools/).
