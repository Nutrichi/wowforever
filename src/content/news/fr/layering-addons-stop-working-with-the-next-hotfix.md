Les addons qui affichent ou changent votre layer ne fonctionneront bientôt plus dans World of Warcraft: Forever. Un prochain hotfix, 1.60.1, masque l'ID de royaume dans les données des créatures, familiers, véhicules et objets. Blizzard l'écrit dans ses notes pour les créateurs d'addons. La date du hotfix n'est pas connue.

## Ce qui change

Chaque créature et chaque objet du jeu a un identifiant, un GUID. Jusqu'ici, il indiquait sur quel serveur et dans quel layer il se trouvait. Les addons comme LayerSwap le lisaient pour afficher votre layer et vous déplacer vers un autre. Après le hotfix, l'ID de royaume, l'ID de serveur et l'ID de spawn sont tous masqués.

> The realm ID in creature, vehicle, pet and game object GUIDs is now obfuscated along with the server ID and spawn ID.
>
> This will also apply to Forever in an upcoming 1.60.1 hotfix.

Le changement vient du patch 12.1.7 de Midnight, dans la sixième build du PTR. Sur le forum, des joueurs attendent le hotfix avec la maintenance hebdomadaire du 24 novembre. Blizzard n'a confirmé aucune date.

## Pourquoi les joueurs s'en soucient

Le layering divise un royaume en copies du monde, pour que les zones ne débordent pas. Avec un addon, des joueurs sautaient vers un layer plus calme pour taper un rare ou un monstre de quête, ou pour fuir un combat sur un royaume PvP. Certains messages du forum parlent d'abus. D'autres demandent plus de layers avec moins de joueurs chacun, pour que les quêtes restent faisables dans les zones chargées. Blizzard ne dit pas si les layers eux-mêmes changent.

Comment un groupe vous déplace vers un layer est expliqué dans [notre article sur Refresh Now](/fr/news/press-refresh-now-to-see-your-new-group/).

## Liens d'invitation dans le chat

Un second changement arrive dans Forever avec un patch ultérieur. Les liens d'invitation vers une communauté ou une guilde dans le chat devront utiliser le lien standard, avec le vrai nom du club ou de la guilde. Les messages avec un texte de lien personnalisé ou déguisé sont refusés.
