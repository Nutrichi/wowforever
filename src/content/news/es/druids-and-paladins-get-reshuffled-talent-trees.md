Druids y Paladins tienen una nueva disposición de talentos a días del lanzamiento de World of Warcraft: Forever. Hay talentos movidos y otros nuevos, como Lacerate y Bloom. Los Mages también cambian mucho. Las correcciones ya están activas, pero las notas de desarrollo no las confirman.

## Druid

| Talento | Cambio |
|---|---|
| **Lacerate** | Talento nuevo |
| **Berserk** | Eliminado |
| **Genesis** | Daño y curación periódicos 2/4/6/8/10% (antes 1/2/3/4/5%) |
| **Leader of the Pack** | Ahora todo el crítico (antes solo cuerpo a cuerpo y a distancia) |
| **Primal Bite** | Daño 42/62/77 (antes 26/38/59), nueva posición |
| **Shifting Power** | Enfriamiento 8 segundos (antes 16) |
| **Bloom** | Talento nuevo |
| **Naturalist** | También acorta el lanzamiento de Wild Growth, todo el daño 2/4/6/8/10% (antes 1/2/3/4/5%) |
| **Swiftmend** | Ahora requiere tu propio Regrowth o Rejuvenation (antes cualquiera) |
| **Wild Growth** | Ahora 3 segundos de lanzamiento |

## Paladin

| Talento | Cambio |
|---|---|
| **Boundless Light** | Talento nuevo |
| **Oath of Light** | Talento nuevo |
| **Shieldsworn** | Talento nuevo |
| **Stoicism** | Talento nuevo |
| **Turn Evil** | Habilidad nueva |
| **Divine Precision** | 2 rangos, 8% de hit Holy al máximo (antes 18%), Silence 20% más corto |
| **Holy Power** | Bonificación de curación crítica 10/20/30/40/50% (antes probabilidad) |
| **Improved Seals** | 5 rangos hasta 15% (antes 3 rangos, 9%) |
| **Light's Vigil** | Ya no se activa sobre un enemigo |
| **Reverence** | 2 rangos (antes 3), sigue 30% de regeneración de maná al máximo |
| **Spiritual Focus** | 5 rangos (antes 2), hasta 70% de probabilidad |
| **Righteous Fury** | Se aprende en el nivel 10 (antes 16) |
| **Holy Shield** | 32% menos de daño, coste de maná 100 (antes 150) |
| **Improved Righteous Fury** | Daño recibido reducido 3/6/9% (antes 2/4/6%) |
| **Iron Creed** | 3 rangos (antes 5), 30% de amenaza al máximo (antes 15%), reducción de daño 6% (antes 10%) |
| **Sacred Duty** | Ya sin Stamina, Forbearance 10 segundos más corto al máximo |
| **Shield Specialization** | 2 rangos (antes 3), mismos valores al máximo |
| **Swift Judgement** | Efecto nuevo |
| **Templar's Bulwark** | Ahora se puede disipar con magia |
| **Champion of the Light** | 5 rangos (antes 3), mismo daño de hechizos al máximo, lanzamiento de Hammer of Wrath 1 segundo más corto |
| **Conviction** | 3 rangos (antes 5), todos los hechizos 6% al máximo (antes 5%) |
| **Two-Handed Weapon Specialization** | Solo daño físico (antes todo), 20% menos de amenaza al máximo |
| **Unsealed Wrath** | Efecto nuevo |
| **Vindication** | Ya no aumenta el poder de ataque |

## Mage

| Talento | Cambio |
|---|---|
| **Arcane Focus** | Eliminado |
| **Arcane Blast** | 12% de Intellect por acumulación (antes 15%), coste de maná +100% (antes 175%), efecto 18 segundos (antes 15) |
| **Arcane Resilience** | Ahora fila 1 con 3 rangos, el rango 3 da armadura igual al 75% de Intellect |
| **Missile Barrage** | Pasa a la fila 2 (antes 1) |
| **Accelerant** | Nuevo nombre de Improved Fireball, también acorta el lanzamiento de Arcane Wrath |
| **Critical Mass** | 6% de crítico en rango 3 (antes 10% en rango 5) |
| **Improved Fire Blast** | Ahora fila 3 (antes 1) |
| **Incineration** | 10% de crítico para Fire Blast, Ice Lance, Arcane Blast y Scorch en rango 5 (antes 6% en rango 3) |
| **Arctic Reach** | También aumenta el alcance de Ice Lance |
| **Ice Barrier** | Daño de Frost +15% (antes 3%), 5% extra con escudo (antes 3%) |
| **Winter's Chill** | Siguiente Cone of Cold +20% de daño (antes 5%) |
| **Ice Lance** | 300% de daño adicional a objetivos congelados (antes 200%), ahora 8 segundos de enfriamiento |
| **Precision** | Nuevo nombre de Elemental Precision, ahora toda la probabilidad de crítico (antes ciertos hechizos) |

## Otras clases

| Talento | Cambio |
|---|---|
| **Pathfinding** | Hunter: fila 3 de Beast Mastery (antes 2) |
| **Shadow Word: Death** | Priest: 30% de daño de retroceso (antes 10%) |
| **Holy Binding** | Priest: nuevo talento Holy |
| **Improved Drains** | Warlock: más maná con Drain Mana (en lugar de Wrack) |
| **Revenge** | Warrior: 25% del poder de ataque en todos los rangos |

Los cambios aún pueden variar, y el lanzamiento llega el 5 de noviembre a las 00:00, hora belga. Blizzard no ha explicado el motivo.
