The name check of World of Warcraft: Forever blocked more names than intended during name reservation. Names that contain the letters c-o-n, for example, were refused by mistake. Blizzard fixes it with the next realm restart in each region.

Kaivax of Blizzard posted the [notice on the forums](https://us.forums.blizzard.com/en/wow/t/overly-restrictive-name-check-and-fix-incoming-october-27/2394467) on 28 October at 02:28 Belgian time. The game keeps a list of restricted names. Those are names that are not offensive but that Blizzard blocks anyway, such as major characters from Warcraft lore, or names that cause technical problems. A bug made that check too strict.

Anyone who got the message "That name is restricted" for a name that should be allowed can try again after the restart. When the restarts take place in each region, Blizzard does not say. Which other names were hit is not known either.

The rules for a name are in [names allow 2 to 12 letters and no apostrophes](/news/names-allow-2-to-12-letters-and-no-apostrophes/). Name reservation [opened on 27 October](/news/early-name-reservation-opens-on-27-october/). On Australian realms a second bug [hides the Roleplay rulesets](/news/blizzard-opens-portal-room-and-warns-oceania/) when you create another character first. WoW Forever launches on 4 November.
