Every character in World of Warcraft: Forever carries two names. Together they make a full name that has to be unique within a region. Blizzard explained the system in a post on 21 September. It comes down to a first name and a surname.

![The Full Name field at character creation, with a box for the main name and a box for the secondary name](../../../assets/posts/2026-09-21-wow-forever-full-name-field.png)

## The pair is what counts

A first name that someone else already took is not automatically lost, writes Blizzard. What has to be free is the whole combination. Two characters can carry the same first name as long as their full names differ.

Because Forever has no realms, that check runs across an entire region instead of one server. Blizzard calls that part of keeping names recognisable over time.

## What a second name can do

The second name is meant to widen the choice rather than narrow it, writes Blizzard. It can suggest a family, a place, a reputation or something that works like a title.

Blizzard gives its own example: Asha Brightvale, Thalen Brightvale and Mira Brightvale share a family-style second name while each keeps a different first one. A guild can do the same with a shared theme, as long as every full combination is still free in the region.

## Turning the second name off

A player who wants the plainer look can hide the second name in the world. It sits in the Game Menu under Options, then Nameplates, as the checkbox My Secondary Name.

![The Nameplates options in the game, with the checkbox My Secondary Name at the top](../../../assets/posts/2026-09-21-wow-forever-nameplates-secondary-name.png)

The second name then disappears above the character, writes Blizzard, but it still shows in chat.

## The rules did not loosen

Names keep to the in-game code of conduct. Certain words, spellings and repeated-character patterns stay restricted, along with names that cause confusion or impersonate Blizzard or the World of Warcraft team.

Splitting a restricted word over the two names does not get around that, writes Blizzard, because the system can weigh both parts together. Blizzard [took beta access away](/news/offensive-names-cost-players-their-beta-access/) from players over their names earlier the same weekend.

## Reserving a name

Early Name Reservation runs from 27 October to 3 November 2026, for eligible upgrade purchases. Names go first come, first served, and a desired name is never guaranteed.

A player whose combination is taken or refused has to pick another one, or fall back on the random name generator in the game.
