Druids and Paladins have new talent layouts days before the launch of World of Warcraft: Forever. Talents moved, and new ones such as Lacerate and Bloom appeared. Mages also see many changes. The hotfixes are live, but development notes do not confirm them.

## Druid

| Talent | Change |
|---|---|
| **Lacerate** | New talent |
| **Berserk** | Removed |
| **Genesis** | Periodic damage and healing 2/4/6/8/10% (was 1/2/3/4/5%) |
| **Leader of the Pack** | Now all critical strike (was only melee and ranged) |
| **Primal Bite** | Damage 42/62/77 (was 26/38/59), new position |
| **Shifting Power** | Cooldown 8 seconds (was 16) |
| **Bloom** | New talent |
| **Naturalist** | Also shortens the cast of Wild Growth, all damage 2/4/6/8/10% (was 1/2/3/4/5%) |
| **Swiftmend** | Now needs your own Regrowth or Rejuvenation (was any) |
| **Wild Growth** | Now a 3 second cast |

## Paladin

| Talent | Change |
|---|---|
| **Boundless Light** | New talent |
| **Oath of Light** | New talent |
| **Shieldsworn** | New talent |
| **Stoicism** | New talent |
| **Turn Evil** | New ability |
| **Divine Precision** | 2 ranks, 8% Holy hit at max (was 18%), Silence 20% shorter |
| **Holy Power** | 10/20/30/40/50% critical healing bonus (was chance) |
| **Improved Seals** | 5 ranks up to 15% (was 3 ranks, 9%) |
| **Light's Vigil** | No longer triggers on an enemy |
| **Reverence** | 2 ranks (was 3), still 30% mana regeneration at max |
| **Spiritual Focus** | 5 ranks (was 2), up to 70% chance |
| **Righteous Fury** | Learned at level 10 (was 16) |
| **Holy Shield** | 32% less damage, mana cost 100 (was 150) |
| **Improved Righteous Fury** | Damage taken down 3/6/9% (was 2/4/6%) |
| **Iron Creed** | 3 ranks (was 5), 30% threat at max (was 15%), damage reduction 6% (was 10%) |
| **Sacred Duty** | No more Stamina, Forbearance 10 seconds shorter at max |
| **Shield Specialization** | 2 ranks (was 3), same values at max |
| **Swift Judgement** | New effect |
| **Templar's Bulwark** | Can now be magic dispelled |
| **Champion of the Light** | 5 ranks (was 3), same spell damage at max, Hammer of Wrath cast 1 second shorter |
| **Conviction** | 3 ranks (was 5), all spells 6% at max (was 5%) |
| **Two-Handed Weapon Specialization** | Physical damage only (was all), 20% less threat at max |
| **Unsealed Wrath** | New effect |
| **Vindication** | No longer raises attack power |

## Mage

| Talent | Change |
|---|---|
| **Arcane Focus** | Removed |
| **Arcane Blast** | 12% Intellect per stack (was 15%), mana cost +100% (was 175%), buff 18 seconds (was 15) |
| **Arcane Resilience** | Now row 1 with 3 ranks, rank 3 gives armor equal to 75% of Intellect |
| **Missile Barrage** | Moved to row 2 (was row 1) |
| **Accelerant** | New name of Improved Fireball, also shortens the cast of Arcane Wrath |
| **Critical Mass** | 6% crit at rank 3 (was 10% at rank 5) |
| **Improved Fire Blast** | Now row 3 (was row 1) |
| **Incineration** | 10% crit for Fire Blast, Ice Lance, Arcane Blast and Scorch at rank 5 (was 6% at rank 3) |
| **Arctic Reach** | Also raises the range of Ice Lance |
| **Ice Barrier** | Frost damage +15% (was 3%), extra 5% while shielded (was 3%) |
| **Winter's Chill** | Next Cone of Cold +20% damage (was 5%) |
| **Ice Lance** | 300% bonus damage on frozen targets (was 200%), now an 8 second cooldown |
| **Precision** | New name of Elemental Precision, now all crit chance (was select spells) |

## Other classes

| Talent | Change |
|---|---|
| **Pathfinding** | Hunter: row 3 of Beast Mastery (was row 2) |
| **Shadow Word: Death** | Priest: 30% backlash damage (was 10%) |
| **Holy Binding** | Priest: new Holy talent |
| **Improved Drains** | Warlock: more mana from Drain Mana (instead of Wrack) |
| **Revenge** | Warrior: 25% of attack power at all ranks |

The changes can still move, and the launch follows on 5 November at 00:00 Belgian time. Why Blizzard made them, it has not said.
