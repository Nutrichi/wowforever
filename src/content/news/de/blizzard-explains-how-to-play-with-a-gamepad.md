Blizzard hat eine vollständige Anleitung zum Spielen von World of Warcraft: Forever mit Gamepad veröffentlicht. Jeder XInput-Controller funktioniert, mit Symbolen von Xbox und PlayStation auf dem Bildschirm. Drei Sätze aus vier Aktionsleisten ergeben 84 Plätze. Die Steuerung ist noch eine funktionierende Beta.

## Einschalten

Drücke Escape, öffne Options und wähle Gamepad unter Gameplay. In den Gamepad-Einstellungen passt du die Kamera, den HUD Modifier, den Frame Focus Style, die Aktionsleisten, das Anvisieren und die Optionen für Raid-Ziele an. Auf einem Controller mit Beleuchtung leuchtet das Licht rot für einen Horde-Charakter und blau für einen Alliance-Charakter.

## Die Tasten

Blizzard nutzt die Namen der Xbox-Tasten:

| Taste | Was sie tut |
|---|---|
| **Linker Stick** | Bewegen |
| **Rechter Stick** | Kamera |
| **LB** | Freundliches Ziel |
| **RB** | Feindliches Ziel |
| **X** | Interagieren |
| **A** | Springen |
| **B** | Zurück |
| **Y** | Betrachten |
| **LT, RT, LT + RT** | Andere Aktionsleiste, solange du sie hältst |
| **Menu** | Hauptmenü |
| **View** | Change Focus Frame |

Die Aktionstasten können auch Zauber tragen. Die Oberfläche auf dem Bildschirm folgt dem Aufbau des Controllers, jedes Feld sitzt dort, wo seine Tasten sind.

## Vier Leisten, drei Sätze

Das HUD zeigt vier Aktionsleisten mit demselben Tastenaufbau. Halte LT, RT oder beide, um zu wechseln, und lass los, um zur ersten Leiste zurückzukehren. Ein Mage kann vier Zauber auf eine Richtung des Steuerkreuzes legen:

| Tasten | Zauber |
|---|---|
| **Hoch** | Polymorph |
| **LT + hoch** | Fireball |
| **RT + hoch** | Frostbolt |
| **LT + RT + hoch** | <a class="wf-wh wf-spell" href="https://www.wowhead.com/forever/spell=10"><img class="wf-wh__icon" src="/wh/spell_frost_icestorm.jpg" alt="" width="18" height="18" loading="lazy" decoding="async">Blizzard</a> |

Das ist ein Beispiel, keine feste Belegung. Dazu gibt es drei Sätze von Aktionsleisten: Halte LB + RB und drücke links oder rechts auf dem Steuerkreuz. Ein Satz hat vier Leisten mit 28 Plätzen, 84 Plätze für alle drei Sätze.

## Kurzbefehle

Halte beide Schultertasten und drücke eine dritte Taste:

| Kurzbefehl | Öffnet |
|---|---|
| **LB + RB + B** | Rucksack |
| **LB + RB + hoch** | Questtracker |
| **LB + RB + runter** | Chat |
| **LB + RB + Y** | Buffs |

Dieselben Fenster sind im Radialmenü. Zum Schreiben im Chat brauchst du weiter eine Tastatur. Eine Legende oben links zeigt die Steuerung und wird größer, wenn eine Aktion mehr Optionen hat. Die meisten Fenster haben unten eine Leiste mit ihren Tasten, aber noch nicht alle.

## Noch in der Beta

Blizzard nennt die Gamepad-Steuerung eine funktionierende Beta. Taschen und Menüs bekommen weitere Änderungen, damit sie mit Controller leichter gehen. Ganz ohne Tastatur zu spielen ist das Ziel auf längere Sicht.

Forever kommt nicht auf Konsolen: [Xbox bestätigte, dass das Spiel auf PC und Mac bleibt](/de/news/forever-stays-on-pc-and-mac-but-plays-with-a-controller/). Die anderen eingebauten Werkzeuge stehen in unserem [Guide zu den eingebauten UI-Tools](/de/guides/built-in-ui-tools/).
