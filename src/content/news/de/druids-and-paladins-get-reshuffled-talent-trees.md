Druids und Paladins haben Tage vor dem Start von World of Warcraft: Forever eine neue Talentanordnung. Talente sind umgezogen, und neue wie Lacerate und Bloom kamen hinzu. Auch Mages ändern sich stark. Die Hotfixes sind aktiv, Entwicklungsnotizen bestätigen sie aber nicht.

## Druid

| Talent | Änderung |
|---|---|
| **Lacerate** | Neues Talent |
| **Berserk** | Entfernt |
| **Genesis** | Periodischer Schaden und Heilung 2/4/6/8/10% (vorher 1/2/3/4/5%) |
| **Leader of the Pack** | Jetzt alle kritischen Treffer (vorher nur Nah- und Fernkampf) |
| **Primal Bite** | Schaden 42/62/77 (vorher 26/38/59), neue Position |
| **Shifting Power** | Cooldown 8 Sekunden (vorher 16) |
| **Bloom** | Neues Talent |
| **Naturalist** | Verkürzt auch die Zauberzeit von Wild Growth, aller Schaden 2/4/6/8/10% (vorher 1/2/3/4/5%) |
| **Swiftmend** | Braucht jetzt dein eigenes Regrowth oder Rejuvenation (vorher beliebig) |
| **Wild Growth** | Jetzt 3 Sekunden Zauberzeit |

| **Oath of Light** | Neues Talent |

| **Divine Precision** | 2 Ränge, 8% Holy-Hit im Maximum (vorher 18%), Silence 20% kürzer |

| **Improved Seals** | 5 Ränge bis 15% (vorher 3 Ränge, 9%) |
| **Light's Vigil** | Löst nicht mehr auf einem Gegner aus |
| **Reverence** | 2 Ränge (vorher 3), weiterhin 30% Manaregeneration im Maximum |
| **Spiritual Focus** | 5 Ränge (vorher 2), bis 70% Chance |
| **Righteous Fury** | Erlernbar ab Level 10 (vorher 16) |
| **Holy Shield** | 32% weniger Schaden, Manakosten 100 (vorher 150) |
| **Improved Righteous Fury** | Erlittener Schaden 3/6/9% niedriger (vorher 2/4/6%) |
| **Iron Creed** | 3 Ränge (vorher 5), 30% Bedrohung im Maximum (vorher 15%), Schadensreduktion 6% (vorher 10%) |
| **Sacred Duty** | Keine Stamina mehr, Forbearance im Maximum 10 Sekunden kürzer |

## Mage

| Talent | Änderung |
|---|---|
| **Arcane Focus** | Entfernt |
| **Arcane Blast** | 12% Intellect pro Stapel (vorher 15%), Manakosten +100% (vorher 175%), Effekt 18 Sekunden (vorher 15) |
| **Arcane Resilience** | Jetzt Reihe 1 mit 3 Rängen, Rang 3 gibt Rüstung in Höhe von 75% des Intellect |
| **Missile Barrage** | Nach Reihe 2 verschoben (vorher 1) |
| **Accelerant** | Neuer Name von Improved Fireball, verkürzt auch die Zauberzeit von Arcane Wrath |
| **Critical Mass** | 6% Krit auf Rang 3 (vorher 10% auf Rang 5) |
| **Improved Fire Blast** | Jetzt Reihe 3 (vorher 1) |
| **Incineration** | 10% Krit für Fire Blast, Ice Lance, Arcane Blast und Scorch auf Rang 5 (vorher 6% auf Rang 3) |
| **Arctic Reach** | Erhöht auch die Reichweite von Ice Lance |
| **Ice Barrier** | Frost-Schaden +15% (vorher 3%), zusätzlich 5% mit Schild (vorher 3%) |
| **Winter's Chill** | Nächstes Cone of Cold +20% Schaden (vorher 5%) |
| **Ice Lance** | 300% Bonusschaden an gefrorenen Zielen (vorher 200%), jetzt 8 Sekunden Cooldown |
| **Precision** | Neuer Name von Elemental Precision, jetzt alle Kritchancen (vorher bestimmte Zauber) |

## Andere Klassen

| Talent | Änderung |
|---|---|
| **Pathfinding** | Hunter: Reihe 3 von Beast Mastery (vorher 2) |
| **Shadow Word: Death** | Priest: 30% Rückschlagschaden (vorher 10%) |
| **Holy Binding** | Priest: neues Holy-Talent |
| **Improved Drains** | Warlock: mehr Mana durch Drain Mana (statt Wrack) |
| **Revenge** | Warrior: 25% der Angriffskraft auf allen Rängen |

Die Änderungen können sich noch verschieben, und der Start folgt am 5. November um 00:00 Uhr belgischer Zeit. Warum sie kommen, sagt Blizzard nicht.
